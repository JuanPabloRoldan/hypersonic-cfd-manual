# Mutation++

Open-source library (von Karman Institute) for thermodynamic, transport and chemical-kinetic properties of high-temperature gas mixtures: the [closures](../reference/foundations/closing-the-system.md) of a reacting CFD code, packaged so several codes can share them (SU2-NEMO, PATO and others).

It provides multi-temperature thermodynamics ([energy modes](../reference/thermo/energy-modes.md)), transport from Chapman–Enskog theory including Stefan–Maxwell diffusion ([transport and diffusion](../reference/thermo/transport-and-diffusion.md)), finite-rate mechanisms ([finite-rate chemistry](../reference/thermo/finite-rate-chemistry.md)), equilibrium calculations and gas–surface interaction models.
